# Continuing from earned milestones

The Extras requirement calls for actual achievement conditions and genuine
challenge progress. The current catalogue already has 45 achievements and 14 challenges
using 43 facts. Its achievement detail previously ended with Close, so an earned
fact did not show where it contributed to a larger existing challenge.

An earned achievement now offers **View Challenge** when an unfinished challenge
uses that exact fact at an equal or higher target. The nearest target comes first;
when targets match, current overall progress breaks the tie, then the existing
catalogue order. The detail shows the challenge title and actual percentage.
Completed challenges are omitted. If no such challenge exists, the detail keeps
Close without inventing a follow-up. An unfinished achievement instead links to
its existing gameplay page. These links only navigate; they do not perform an
action or claim that its requirements are currently met.

Creator activity links open the actual YouTuber or Streamer studio by kind,
including its existing profile setup path. The general studio-post challenge
goal opens Special Careers, where either kind can be chosen; its live-minute
goal opens the Streamer studio. The account-scoped collaborations screen is a
separate feature and cannot serve as an account-free production destination.

Challenge details recognise the achievements already earned within their actual
goal targets. For example, a child with twelve funded care months and 48 hobby
proficiency sees A Year of Care under Care and Craft, whose progress remains 98%.
Finding Your Rhythm appears only after normal practice reaches 50 proficiency.
An achievement with a higher target than the challenge does not become one of
that challenge's required milestones.

All existing facts, IDs, targets, catalogue totals and earned conditions remain
unchanged. No money, stats, probabilities, qualifications, unlocks, journal rows,
random draws, saves or new rewards are created. The recognition and continuation
follow the selected person's retained history and current timeline. Switching
life or active person clears an open achievement detail; an unrelated saved
revision preserves it and updates its factual values.

The catalogue remains virtualised. The complete factual projection stays memoised
by world; opening, closing and filtering details do not repeatedly read all
history. Only the open achievement derives a continuation from the already
projected challenges. The shared milestone modal retains Close/hardware Back and
adds one optional navigation action, disabled while busy. Existing modal users
keep their previous defaults.

Focused tests use unchanged genuine child and employed-graduate fixtures, actual
monthly practice and a paid investment command. Connected SQLite browsing checks
every row in all eight tables, the complete canonical world, a fresh repository
cold read, actual save retention and real life switching. Original fixtures,
game/persistence code and version tags remain untouched. These are scoped
domain/UI checks, without new native, broad balance or release acceptance claims.

The initial 16 focused checks across four suites pass in 15.502 seconds, including
the existing Extras and shared modal interaction checks. The creator-destination
follow-up passes all seven affected UI checks across two suites in 14.627 seconds:
both milestone shortcuts reach the real matching studio and profile setup form,
and both Creative Consistency shortcuts reach actionable feature pages. Those
