# Introductions through actual hobby practice

The eight existing local hobby routines now offer an optional introduction after
an actually attended, paid month of the current plan. A review shows the original
responsible adult, already-paid access, zero additional cost and the calendar-year
limit. Browsing, cancellation and unavailable/current choices save nothing.

The participant must still be physically available at the plan's actual home
location, with the existing health, fatigue and career-training restrictions.
A child needs the original consenting parent or guardian, still an adult in the
same household and location and physically available. Another parent cannot
silently replace them. Adults require their own current arrangement. Unpaid,
old-month and former-plan practice cannot qualify; manual practice cannot replace
paid attendance. Already-paid access needs no second cash reserve.

One introduction is available per hobby per calendar year. Changing, stopping or
restarting a routine does not reset that limit. Only this explicit action checks
up to the first 64 saved hobby records for an unconnected, age-appropriate,
actually paid and currently available local participant in the same hobby.
Otherwise the existing ordinary contact constructor creates one local person.
Children meet someone their age; adults meet another adult within eight years
of their actual current age. No ordinary render or
monthly hook scans or sorts the population for hobby peers.

The existing relationship constructor establishes a bond and trust of 35, with
its truthful classmate/acquaintance role and no instant friendship or romance.
A relationship memory records the actual hobby introduction and year; the
existing journal records the person's name. A bounded recent list opens the real
person route. This records where people met, without promising their continued
enrolment, a qualification, owned equipment, proficiency, following or income.
The player's previous practice, funds and receipts remain unchanged. A generated
adult keeps the ordinary constructor's existing background finances and work;
these are not payments to the player.

The command binds the reviewed attendance month as well as the current plan and
payer. A saved review cannot silently switch to a later month's paid access.
The review closes only after durable dispatch succeeds. Failure retains its exact
command and terms with one accessible error; busy submission prevents duplicate
confirm/cancel. The route key includes life, active person and hobby, preserving
same-context drafts across revisions while clearing old-identity reviews.

This is a new optional command and relationship/journal history, using existing
saved fields rather than a new model collection. No engine/model/version tags,
persistence code or original fixtures change in this branch. Integration owns
the consolidated gameplay/version review before release.

Focused evidence uses the original `v28-ordinary-hobby-archive.json`: the saved
nine-year-old already has paid current guitar and reading attendance. New UI
checks use a temporary on-disk SQLite database, exact all-eight-table rollback,
warm retry with zero checkpoint unpack, closed-connection cold resume, saved
person/result acknowledgement and no duplicate creation. Original snapshot bytes
remain exact. Domain checks cover both saved hobbies, all eight configured adult
routine/reuse cases, stale terms and routine changes. Explicit resolver-only
guard fixtures configure restrictions without claiming valid migrated saves or
natural travel/hospital/custody journeys. No native acceptance, long policy,
cross-country balance or complete release claim is made here.
