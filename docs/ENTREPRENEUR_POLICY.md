# Natural famous-entrepreneur acceptance policy

Specification 13.2 Scenario C requires Birth → School → Social Media → Fame →
Business → Brand Deals → Investments → Family → Death. Existing funded-adult
social/company unit checks and ordinary work/leisure lifetime policies do not
establish this complete sequence. This separate policy adds evidence without
changing gameplay or demanding that every naturally generated life succeeds.

Every actual command contributes canonical bytes to a saved trace hash. Complete
failure diagnostics retain the last valid world and bounded recent trace.

## Interpretation and execution

Output separates integrity from product coverage. Every reached milestone has
its actual command index/revision/date. Missing phases and early death remain
explicit; seeing every phase in the wrong order does not complete Scenario C.
Natural Fame50/company/family failure can therefore leave all lives incomplete
without disguising the unmet acceptance goal. A command/ledger/conservation
failure fails integrity and exits unsuccessfully.

Use `node tools/run-entrepreneur-sweep.cjs --country US --output EMPTY_DIRECTORY`
for the initial authorised seed900 probe. Only the coordinator may authorise the
final `--all` twelve-country run after independent review and source freeze.
The output folder contains the unchanged birth databases, canonical per-life
command traces, per-life summaries and aggregate result. No new twelve-country
run is claimed in this preregistration.

Fourteen focused checks pass in1.427seconds: source/cohort pins, canonical trace
bytes, early-death/unordered goal reporting, visible decision policy without
hidden-outcome access, exact fee-aware quantities, reserve-protected public
reputation, actual production checkpoint equality, solvent/insolvent estate
conservation and matching real heir/creditor/tax/charity receipts. Syntax and
whitespace checks and focused strict test/source compilation pass. The final v2
natural-life run is unrun pending review.
