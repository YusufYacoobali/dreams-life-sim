# Date activities

The Person → Date Activities flow offers four authored options. Costs use the
existing country-currency date budget, with exact minor-unit rounding:

| Activity | Budget fraction | Bond | Happiness | Energy |
| --- | ---: | ---: | ---: | ---: |
| Walk | 0 | +5 | +4 | −5 |
| Coffee | 1/4 | +6 | +4 | −3 |
| Meal | 1 | +7 | +6 | −4 |
| Movie | 3/4 | +4 | +6 | −3 |

Only actual consent charges the reviewed cost and applies these capped changes,
along with the existing +5 trust and dating/partner memory rules. A refusal
charges nothing, creates no romance and retains the existing happiness−2 rule.
All four choices and legacy dates share one attempt per person per calendar year.

The shared read-only helper applies existing adult, mutual-preference, family,
exclusivity, presence, custody, hospital and event guards plus available cash.
The review shows actual capped changes. Selecting or cancelling draws nothing.
An actual attempt uses the existing single outcomes-stream consent draw.

Omitting `activity` preserves the original meal/date resolver and copy exactly.
No currency, asset, stored collection, catalogue entry or additional version is
introduced; this joins the already-coordinated World39/engine40/content14 batch.
