# Durable Exercise review

Exercise previously cleared the selected session before dispatch finished and
passed no save error into its confirmation. A failed receipt write therefore
lost the visible activity, fee and energy review.

The route now uses the existing Health review hook. The actual selected activity
and displayed fee/energy terms remain after a failed dispatch, with one polite
inline alert. The confirmation closes after durable success. Its immediate
submission guard blocks duplicate callbacks, alternative sessions, cancellation
and Android Back while saving. Life/person identity changes discard the old
review; unrelated actual revisions retain the reviewed activity and terms.

The shared helper receives only a type extension accepting the actual existing
exercise command. Its runtime is unchanged, and its narrower medical-eligibility
helper is unchanged. Exercise retains all six existing activity choices, age,
health and once-year control rules, fees, caregiver wording and energy terms.
No core command, stat gain, injury chance, funding rule, availability rule or
random draw changes. Existing optional feedback and reduced-motion behaviour
remain shared UI behaviour.

Focused connected tests use the unchanged v3 employed graduate, without adding
age, funds, health, energy, fitness or outcome overrides. That archive's original
producer had fixture-initialised Smarts/Discipline; this is continuation of a
genuine recorded fixture, not a newly claimed natural birth-to-career journey.
Free walking and paid personal training both cover exact all-eight-table/world
receipt rollback, retained selected terms and one alert, warm retry with no full
checkpoint unpack, exact old backup bytes, a closed/reopened SQLite connection,
one durable result acknowledgement and the shared annual limit. Separate
checks cover immediate duplicate callbacks, held saving/Back, an unrelated real
meditation revision, an actual new-life switch and unchanged newborn age gates.
An unchanged separate native story archive and its original historical payloads,
metadata, backups and receipts remain exact throughout.

These are component/on-disk persistence checks. They do not claim new native
visual/accessibility acceptance, exercise balance, all injuries, all currencies,
country cohorts or a whole-life journey. No engine, schema/version, persistence,
immutable fixture or main-branch source is changed.

Focused verification passes all four connected tests in 29.414 seconds, strict
affected-file application/test types and diff checks. No broader gate was run.
