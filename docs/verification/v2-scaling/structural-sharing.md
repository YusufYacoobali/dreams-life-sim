# Structural sharing and incremental integrity

Production uses a central revocable plain-data draft for ordinary immutable commands. Monthly advancement, monthly-resuming acknowledgements and child continuation use explicit shallow sharing of frozen journal facts with the reference mutable copy for other state. Mutable/untrusted inputs retain full copying and validation. `resolveCommandReference` retains the old copy path; `resolveCommandUsingDraft` tests the full proxy prototype. No new dependency is added.

A full proxy simulation was slower (age 70 light full-year p50 154.8 ms versus the incremental-ledger copy path 115.5 ms). The selected hybrid measures 109.4 ms. Routine p50 at age 70 light is 74.1 → 47.5 ms against the original baseline; extreme finance is 91.1 → 69.4 ms, and extreme complete year 514.6 → 409.6 ms. All twelve matched hybrid outcomes preserve complete canonical-world SHA, RNG, commands and exact checkpoint SHA. Separate host runs are descriptive; tails and raw samples are retained in `structural-sharing.json.gz` and `draft-prototype.json.gz`.

Private draft provenance records every write, nested mutation, deletion, reorder and truncation. Only finished frozen outputs can offer append proofs; the model additionally requires a privately certified predecessor. Journal IDs use a persistent lookup; per-person earliest facts and the latest fact prove all unchanged cross-references and birth/date bounds. Old-row edits and unknown provenance fall back. Journal lineage contains lengths/tokens, never old worlds or arrays, and distinguishes branches and skipped UI publications. Projection processes only appended entries while retaining every old row; immutable list concatenation still copies references.

Pure subsystem validators record their actual root reads, property-presence checks and enumeration. Their results are reusable only when ALL observed immutable branches/primitive values still match, including the ledger when supplied separately. The cache belongs to the model and is published only after all checks succeed. Changed dependencies rerun the complete validator; unknown inputs, legacy data, imports and mutable copies run all checks. Base person/family/account/debt/asset/pending checks remain complete. New validators must retain the existing pure-world-validation contract. No production integrity check is disabled and no periodic spot check substitutes for proof.

Opt-in timing now covers all command types, copy/draft finalization, shape parsing, index construction, freezing, monthly/annual simulation, storage and publication. UI observation can match the exact published revision after dispatch settles. Observers cannot fail gameplay and never receive names or saved content. The existing FlatList virtualization, frame coalescing, row layout retries and manual-scroll behavior are retained because native scrolling evidence does not justify removing them.

Eight focused suites / 53 tests plus strict app/test types passed before the explicit journal-copy follow-up; the final follow-up is recorded in the final verification report. Additional tests prove append-only projection calls age calculation only for new facts, invalid prefixes and references cannot borrow certificates, divergent branches fall back, failed drafts preserve snapshots, and twelve years match the reference after every command. A separate full 3,000-activity trace comparison is retained when complete. Release iPhone/Android, native allocation/GC and final full regression/soak remain open at this checkpoint.
