Implementation and validation scope

Shared artwork88 reusable transparent layers, 1.93 MiB total PNG data. Four face families × eight illustrated head stages, seven visible hairstyles plus bald, and four clothing layers. No generated full-portrait combinations.
Rendering3–7 local image layers per portrait. Direct tint on flat masks only; no multiply, grayscale, filters, remote fetch, runtime raster generation, animation loop or whole-head face stretching. Static PNG require calls bundle offline on Android and iOS.
IdentityExisting face/skin/hair/hairColor indices and 16 preset tuples remain compatible. Clothing is a deterministic function of these saved traits. Age comes from the existing caller. No schema, version, gameplay, navigation, screen layout or unrelated artwork changes.
MemoizationNative image layers are memoized by rendered scalar traits and size. Save-copy object identity, accessible-label changes, decorative toggles and years with the same visible stage/hair colour reuse the drawing.
EvidenceSee validation.json, focused test logs, TypeScript log, Android/iOS export logs and browser checks beside this file. Browser captures verify artwork and shared layout; native hardware frame rate, TalkBack/VoiceOver and iOS/Android device screenshots require those devices.
