Investigation and proposed reusable system

SourceRemote work branch, fd83b19971f57a21f558bba311d395e571980cc7. All portraits alias CharacterPortrait through src/ui/components.tsx.
Saved formatappearance = { face: 0–3, skin: 0–5, hair: 0–7, hairColor: 0–4 }. Presets store these four traits. Gender and identity are independent.
Existing options16 presets. Faces: Oval, Round, Long, Broad. Hairstyles: Bald, Short straight, Cropped curls, Side swept, Shoulder length, Long curls, Bun, Coily afro. Hair colours: Black, Brown, Chestnut, Blond, Auburn (#271D18, #66422D, #B17B43, #E8CC8B, #BB6B42). Skin indices run from very light to deep brown (#F3D5BC, #E5B995, #C88F61, #A86B45, #7E4B30, #4C3026).
Stable identityPlayer traits are copied from creation, NPC traits are seeded, biological children inherit parental face/hair traits and the rounded mean of parental skin indices. Age is derived from dates; rendering never needs fresh randomness. World schema is 41; no migration is needed for an internal renderer replacement.
Current limitationsGrayscale atlas recolouring affects the entire face including eyes and mouth. The head/hair drawing is stretched for face shape. There is no separate back-hair, clothing or shoulders layer. The opaque circular background is fixed to a light colour. Source art has volumetric shading. The renderer uses multiply on iOS/Android API 29+ and colour-matrix filters on older Android.
Proposed artworkUse one common square rig: back hair → clothing/shoulders → ears, neck and anatomically drawn face contour → features → front hair → age accents. Draw four true face contours with shared feature anchors, rather than scaling the whole portrait. Use flat authored skin/hair base masks with separate full-colour features and cel-shadow/outline layers.
CoverageRetain all 16 presets, six skin indices, eight hairstyle IDs (including bald), five hair indices, four face IDs and eight age stages. Generate small layer families, then compose combinations. Newborns retain latent hairstyle choices; greying changes hair fills while facial landmarks preserve identity.
Offline and performanceBundle local transparent artwork with static require calls. Tint only flat colour masks; keep features, shadows and line art separate. Prefer a bounded set of image layers and scalar memoization. Derive a modest clothing palette deterministically from saved appearance traits, so no new save fields or random render calls are needed.
CompatibilityPreserve CharacterPortrait({appearance, age, name, size = 56, decorative = false}), its image label and decorative semantics. Replace its internal drawing centrally; leave navigation, layout, saves and gameplay untouched.
