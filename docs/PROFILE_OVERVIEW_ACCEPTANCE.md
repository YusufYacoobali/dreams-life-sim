# My Life overview and preference saving

Scope: the L02 player profile in [the screen inventory](planning/screens-and-navigation.md), the My Life panel in `design/02-onboarding-life-dashboard-age-up-profile.png`, and the contextual statistics required by [source specification §5.2](planning/source-specification.md). This change does not alter game rules, save formats or historical data.

`app/(game)/profile.tsx` now displays the actual nationality separately from the current residence, age and date of birth. Education, occupation, net worth, residence, marital status, children and reputation use existing records and selectors, with shortcuts to the corresponding existing views. Occupation follows the existing Life dashboard priorities, including custody, public duties, service and full-time creator work. The ten existing percentage stats appear in two groups; Discipline is now visible. No outcomes or future data are generated by opening this page.

The existing adult preference form still saves directly. Unchanged values, including the same attraction set in a different selection order, disable saving and do not dispatch. During saving, its attraction controls and children switch are disabled and only the submitted Save button shows busy status. A failed save retains the exact draft and presents one accessible live error for retry. Changing life or active person resets the local form through the combined identity key.

Focused verification uses genuine existing newborn, graduate/family, relocation, school, military and royal fixtures with the real store, resolver and SQLite repository. `tests/ui/profile-overview-save-flow.test.tsx` checks read-only navigation against all eight database tables, all ten stat values, nationality/residence separation, actual contextual shortcuts, unchanged saves, transaction rollback, a held save and blocked duplicate presses, exact warm retry, a fresh SQLite connection and store cold resume, one persisted result acknowledgement, and life switches where both lives have `person_player`. Original inactive life, backup and historical snapshot payloads remain exact.

Local checks: nine focused tests pass; strict application and test TypeScript checks pass. Native pixels, large-text scrolling, TalkBack speech and physical iOS/Android acceptance are not established by these component tests. The coordinator owns subsequent combined gates and native verification.
