# Cult career artwork

These twelve original transparent illustrations were generated with **Image Gen**
on 23 October 2026. Krea was not used. The brief matched the existing Dreams
career icons: rounded painted objects, navy and royal blue with warm gold,
consistent soft lighting, clear silhouettes, no text or logos. The generated
1448 × 1086 RGBA source remains unchanged at
`/workspace/generated_images/exec-0986981b-c4a9-4617-b16a-3e6ace2d6e3c.png`.

`manifest.json` records its SHA-256 and every runtime derivative's source
rectangle, byte count and SHA-256. Derivatives crop isolated subjects, remove
near-transparent gutter noise with a 2% alpha floor, trim transparent padding
and fit inside 224 × 224 without stretching. The source is not bundled.

The set covers cult leadership, philosophy, doctrines, rules, recruitment,
followers, ceremonies, treasury, headquarters, rivalry, public scandal and
wild claims. `src/assets/CultArt.tsx` bundles all twelve locally, so the game
does not contact an image service. These are activity icons; real inner-circle
people use the existing character portraits.

Source and light-card derivative inspection is complete. Browser component
captures and native export checks are recorded in
`docs/verification/cult-career/`. Browser captures do not establish physical
Android/iOS rendering or performance.
