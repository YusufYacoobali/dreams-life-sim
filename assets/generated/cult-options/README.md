# Cult option icons

Six transparent 256px, single-subject PNGs supply distinct headquarters and
upgrade choices. Total runtime payload: **364,717 bytes**. No existing PNG is
replaced or duplicated. Other cult options reuse clear registered assets or
existing measured atlas crops directly.

Source, brief and registration: [design/cult-options](../../../design/cult-options/README.md).
The local manifest records source and output hashes, dimensions and alpha bounds.
